# GitHub Copilot Instructions

- When generating code, if an `if` statement has only one line in its body, do not enclose that single-line body in curly braces.
  - Example:
    ```csharp
    if (condition)
        DoSomething();
    ```
  - Avoid:
    ```csharp
    if (condition)
    {
        DoSomething();
    }
    ```

- Keep responses concise, professional, and easy to scan.
- Use markdown headings, bullets, and short paragraphs for clarity.
- Follow the existing workspace and C# conventions when updating project files.
